# 日常检查器 · DailyChecker

> 扫一遍本机自动化脚本写出的日志，告诉你 20 款游戏的日常今天做完没有、脚本有没有报错。

一个玻璃风格的 Windows 桌面小工具，功能移植自 OneDragon ScriptChainer 的 `检查日常.py`。与姊妹项目 [自动化更新器](https://github.com/DADiDiDiDA/automate-updater) 共用同一套 PySide6 UI 框架。

| 项目 | 说明 |
| --- | --- |
| 平台 | Windows 10 / 11 |
| 技术栈 | Python 3 · PySide6 · PyInstaller（单文件 exe，便携免安装） |
| 当前版本 | **v1.7.8** |
| 仓库 | [DADiDiDiDA/daily-checker](https://github.com/DADiDiDiDA/daily-checker) |

## 先看这一句：它检查的不是游戏日志

本程序判断日常是否完成，读的是 **MAA / BetterGI / March7thAssistant 这类自动化程序自己写出来的日志**，不是游戏客户端的日志。

```
扫描根目录（默认 D:\Automate，可配多个）
  └─ 自动化程序目录（如 D:\Automate\MFAAFGO）
       └─ 日志文件夹 logs / log / debug / .log（只读顶层文件）
            └─ 按「规则」找完成关键字 / 判断文件是否生成
```

所以「游戏」在本程序里其实是**一条监控项**：名字是游戏，指向的却是某个自动化程序的目录。每日结果、异常（`on_error` / `screencap` 文件夹）、`debug` 目录日志体积、连续无错天数都围绕这个目录展开。

## 快速开始

1. 下载 `DailyChecker.exe`，双击运行（无需安装，配置写在程序旁边）。
2. **设置 → 扫描目录**：确认根目录指向你放自动化程序的位置，默认 `D:\Automate`，可添加多个、可排除子目录、可设扫描深度并「扫描预览」。
3. **判定规则 → 程序检查规则**：给每款游戏绑定一条规则。没设定的游戏会用「默认规则」，并在列表里置顶提醒。
4. 按 `F5` 检查一轮，首页看结果。
5. 可选：设置页配置钉钉通知、开机自启、定时检查、关窗驻留托盘。

## 四个核心概念

| 概念 | 是什么 | 在哪改 |
| --- | --- | --- |
| **游戏** | 一条监控项：显示名 + 自动化程序根目录 + 完成提示语。内置 20 款，可自行增删 | 程序检查规则页「添加游戏 / 编辑」 |
| **规则（规则库）** | 「怎么算完成」：判定方式 + 关键字 / 文件名 + 扫描后缀。一条规则可被多款游戏共用 | 判定规则 → 规则库 |
| **文件夹关键词映射** | 把程序文件夹名映射成游戏显示名，用于异常监控归属；文件夹名**包含**关键词即命中，取最长匹配 | 判定规则 → 文件夹关键词映射 |
| **程序检查规则** | 游戏 ↔ 规则的绑定表，外加每款游戏的日志阈值与分项开关 | 判定规则 → 程序检查规则 |

内置 **6 条规则覆盖 20 款游戏**，其中「通用 · 任务已全部完成」一条被 15 款共用（改一次全部生效）。内置文件夹映射 20 条，同样可编辑、删除、一键恢复。

### 五种判定方式

| 方式 | 判定条件 |
| --- | --- |
| 关键字（不限日期） | 日志内容里出现完成关键字，不看文件日期 |
| 关键字（仅今天的日志） | 只搜今天修改过的日志，避免读到昨天的成功记录 |
| 今天有新日志 | 日志文件夹里存在今天修改的日志文件即算完成 |
| 特定文件已生成 | 指定文件名存在即算完成，不看日期 |
| 特定文件今天生成 | 指定文件存在且修改时间是今天 |

一条规则可勾选多种方式，**任一满足即算完成**。

## 功能一览

**日常与异常**
- 逐款扫描自动化程序日志，判定当日日常是否完成；副标题直接写出「未命中「任务已全部完成」· 扫了 1 个 .log」这类可对照的结论
- 异常监控：扫描目录下发现 `on_error` / `screencap` 文件夹即标记异常，按自然日统计连续无错天数
- 存疑判定：`debug` 目录顶层 `.log` 合计体积超过阈值（默认 10MB）标记存疑；有全局总开关 + 每款游戏的分项开关与独立阈值
- 排除管理：不想检查的游戏右键排除，不参与日常 / 异常 / 无错天数统计
- 扫描深度设置与「扫描预览」（只读预览会找到哪些目录与异常文件夹）

**首页与手动状态**
- 统计卡片 + 关注列表，默认「未完成优先」，另有按名称 / 已修复置底 / 默认顺序
- 右键可设「已完成 / 未完成 / 已修复 / 强制已完成 / 清除」。所有记号**仅当天有效，次日 0 点自动清除**
- 「强制已完成」直接判定完成，并让该游戏完全退出首页统计、关注列表、托盘角标与侧栏数字
- 游戏列表与程序检查规则页各有独立排序（含「未完成优先 / 异常优先」「未配置优先」）

**通知与后台**
- 异常监控 / 存疑提醒 / 日常检测 / 日常汇总四条钉钉消息，手动发送前可预览；手动、定时、后台检查均可按设置自动发送
- **默认不带任何 Webhook 凭证**，新设备需自行填写
- 单实例（重复启动唤起已有窗口并转交命令行参数）、托盘驻留、开机自启（注册表值名 `DailyChecker`）、定时检查

**外观**
- 三套皮肤：亚克力（玻璃模糊）/ 莫奈（Material You）/ Miuix（澎湃 OS 风格）
- 明暗模式跟随系统 / 浅色 / 深色；毛玻璃可一键关闭

## 界面导航

| 页面 | 快捷键 | 作用 |
| --- | --- | --- |
| 总览 | `Ctrl+1` | 统计卡片、关注列表、右键打记号 |
| 游戏列表 | `Ctrl+2` | 全部游戏的检查结果、排序、右键操作 |
| 判定规则 → 文件夹关键词映射 | `Ctrl+3` | 文件夹名 → 游戏名映射表 |
| 判定规则 → 规则库 | `Ctrl+3` | 规则的新建 / 编辑 / 复制 / 删除 / 设为默认 |
| 判定规则 → 程序检查规则 | `Ctrl+3` | 游戏绑定规则、阈值、排序 |
| 设置 | `Ctrl+4` | 扫描目录、通知、后台、外观、排除名单 |
| 全页 | `F5` | 立即检查一轮 |

## 命令行参数

| 参数 | 作用 |
| --- | --- |
| `--check` | 启动后立即检查一轮（不自动发通知） |
| `--notify` | 检查后发送通知（配合 `--check`） |
| `--quit-after` | 检查 / 通知完成后自动退出（配合计划任务） |
| `--hidden` / `--tray` / `--silent` / `--background` / `-t` | 后台静默启动，不显示主窗口 |
| `--help` / `-h` | 打印参数说明 |

```powershell
DailyChecker.exe --check --notify --quit-after --hidden
```

常驻托盘时再次带参数启动，参数会转交给已运行的实例。

## 文件与配置

| 路径（相对程序根目录） | 内容 |
| --- | --- |
| `config/config.json` | 全部设置、规则库、游戏绑定、手动状态。 |
| `error_detect_state.json` | 异常监控状态与连续无错天数（原子写入，带 `.tmp` 过渡） |
| `DailyCheck.txt` | 最近一次日常检查的日报 |
| `crash.log` | Qt 事件循环异常的兜底日志 |

- 检测数据目录**默认就是程序根目录**（旧版 `D:\Automate\Cache` 会在首次启动时自动迁移，不丢无错天数），可用 `check.cache_dir` 覆盖。
- 配置采用「默认值 + 浅合并」加载，旧版本配置自动兼容；文件损坏时先备份为 `.corrupt` 再回退默认值。

## 从源码运行 / 重新打包

```powershell
pip install PySide6 pillow pyinstaller
python app.py
python -m PyInstaller DailyChecker.spec --noconfirm --clean
```

依赖：`PySide6`、`pillow`（打包用 `pyinstaller`）。源码目录里的 `config/`、`_test/`、`build/`、`dist/` 均为本地产物，不入库。
