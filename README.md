# 日常检查器 (DailyChecker)

玻璃风格的桌面监控程序（PySide6），与「自动化更新器」同套 UI 框架。
功能移植自 OneDragon ScriptChainer 的 `检查日常.py`。

## 功能

- **日常检测**：20 款游戏逐个扫描**自动化程序写出来的日志**，判断当日日常是否完成
  （不是游戏自己的日志）
- **判定规则库**（v1.3.0）：规则 = 「怎么算完成」（判定方式 + 关键字 / 文件名），
  游戏只决定「看哪个自动化程序目录」。一条规则可被多款游戏共用（如 MAA 系 14 款游戏
  共用「任务已全部完成！」），改一次全部生效；新游戏添加时直接从库里选规则，
  库里没有就先建一条。五种判定方式：
  - 关键字（不限日期）—— 与原脚本一致
  - 关键字（仅今天的日志）—— 只搜今天修改过的日志，避免读到昨天的成功记录
  - 今天有新日志 —— 只要存在今天修改的日志文件即算完成
  - 特定文件已生成 / 特定文件今天生成 —— 比指定文件名（可指定是否今天生成）
- **异常监控**：遍历设置里勾选的扫描目录（默认 `D:\Automate\My-maawork`，
  可添加多个、可排除子目录），发现 `on_error` / `screencap` 文件夹即标记异常，
  按自然日统计每个游戏连续无错天数
- **存疑判定**：扫描目录下游戏的 debug 目录顶层 `.log` 合计体积超过阈值
  （默认 10MB；「判定规则 → 游戏 → 规则」页顶部可开关、改默认值，每行可单独调整）
- **钉钉通知**：异常监控 / 存疑提醒 / 日常检测 / 日常汇总 四条消息，
  手动发送前可预览；手动、定时、后台检查均可按设置自动发送。
  **默认不带任何 Webhook 凭证**，新设备须自行填写（旧配置不受影响）
- **排除管理**：不想检查的游戏右键排除（不参与日常 / 异常 / 无错天数）
- **数据目录可自选**：默认 `D:\Automate\Cache`，与原脚本共用
  `error_detect_state.json`，无错天数连续不重计

## 使用

- `DailyChecker.exe` 便携运行，配置生成在 exe 同目录 `config/config.json`
- 开机自启 / 定时检查 / 关窗驻留托盘均在设置页
- 快捷键：Ctrl+1/2/3/4 切页，F5 开始检查
